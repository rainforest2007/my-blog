# 欢迎来到我的博客

这是一篇关于博客搭建的文章，记录了我使用 React 和 Vite 创建这个博客的过程。

## 为什么选择这个技术栈？

1. **React** - 组件化开发，生态丰富
2. **Vite** - 极速的开发体验
3. **Tailwind CSS** - 快速构建美观界面

## 主要功能

- 📝 博客系统 - 支持 Markdown 编写
- ⏱️ 小应用 - 番茄钟、扫雷等
- 📱 响应式设计 - 适配各种设备

## 示例代码

```javascript
const greeting = "Hello, World!";
console.log(greeting);
```
